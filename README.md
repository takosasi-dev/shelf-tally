# 在庫管理(ShelfTally)

> **開発中。実機では未確認。** ビルドと単体テストは通していますが、端末に入れて動かす確認はまだしていません。

家庭の消耗品(トイレットペーパー・洗剤・調味料・ペットフード・薬など)の残量を記録し、なくなる前に知らせる Android アプリです。

- パッケージ名: `io.github.takosasidev.shelftally`
- **完全オフライン。`INTERNET` の権限を宣言していません。** 記録と写真は端末の中だけに保存し、外へ送りません。バーコードの画像も端末の中だけで処理します。
- Android 8.0(API 26)以上

## 要件定義書から変えた所

- **バーコードの読み取りは ML Kit ではなく ZXing**(`com.google.zxing:core`、Apache-2.0)を使います。ML Kit は Google の独自の規約の下で配られているためです。読む形式は EAN-13(JAN)・EAN-8・UPC-E・CODE 128・QR です。UPC-A は、先頭に 0 を付けた 13 桁の EAN-13 として読みます。
- 期限と定期購入の見回りは、AlarmManager の 1 日 1 回(時刻のずれを許すアラーム)と、アプリを開いたときに行います。

## 構成

| モジュール | 中身 |
|---|---|
| `:core` | Android に依らない Kotlin。残量の判定・予測・期限・定期購入・買い物リスト・絞り込み・集計・バックアップの形式・バーコードの読み取り。`gradlew :core:test` で単体テストが走ります。 |
| `:app` | Compose の画面、Room、通知、Glance のウィジェット、SAF、CameraX。 |

## ビルド

JDK 17 と Android SDK(platform 35 / build-tools 35)が要ります。`local.properties` に `sdk.dir=<SDK の場所>` を書くか、環境変数 `ANDROID_HOME` を決めてから:

```sh
./gradlew :core:test        # ロジックの単体テスト
./gradlew assembleDebug     # -> app/build/outputs/apk/debug/app-debug.apk(debug の鍵で署名)
```

## 権限とその理由

自分で宣言している権限:

| 権限 | 理由 |
|---|---|
| `CAMERA` | バーコードの読み取りと、品目の写真の撮影。使うときに許可を求めます。断っても、手入力と写真の選択で使えます |
| `POST_NOTIFICATIONS` | 低在庫・期限・定期購入のお知らせ(Android 13 以上で許可を求めます) |
| `RECEIVE_BOOT_COMPLETED` | 端末の再起動で消える、1 日 1 回の見回りのアラームを積み直すため |

`INTERNET` は宣言していません。ライブラリが足す権限(ビルドした APK に入ります):

| 権限 | 出どころ | 実際に使うか |
|---|---|---|
| `ACCESS_NETWORK_STATE` | Glance → WorkManager | 使わない。`INTERNET` が無いので通信そのものができない |
| `WAKE_LOCK` / `FOREGROUND_SERVICE` | Glance → WorkManager | Glance がウィジェットを描き直すときに使う。自分では WorkManager に仕事を登録していない |

写真の選択と、バックアップのファイル・フォルダの選択は、端末の選択画面(Photo Picker / SAF)を使うので、ストレージの権限は要りません。

## データの扱い

- `android:allowBackup="false"` なので、Google のクラウドのバックアップには乗りません。退避の手段は、アプリの中のバックアップ(zip)だけです。
- 自動バックアップの zip はパスワードなしで書き出します。保存先のフォルダは自分で選びます。
- DB の版を上げるときは、`AppDatabase.MIGRATIONS` に Migration を足し、`app/schemas/` にできた JSON を commit します。`fallbackToDestructiveMigration()` は使いません。
